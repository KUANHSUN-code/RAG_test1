# 台灣大學生打工權益｜RAG 練習資料集

整理日期：2026-10-18（台灣時間）

包含 16 份 UTF-8 繁體中文 TXT；每份有標題、官方來源網址、短篇教學改寫摘要、測試問題。

重要：本資料集不是官方網站原文的逐字爬取結果。由於本環境無法直接連線抓取網站原始 HTML，使用已查閱之勞動部官方公開網頁資訊，整理為可辨識來源的短篇教學摘要。這有利於快速測試 RAG，但不適合作為真正的長文件切塊 benchmark。並未宣稱已獲得網站全文再利用授權。

建議教學：
1. 先把各 TXT 視為一份 document，按段落或固定 token 數切塊。
2. 計算 embeddings，檢索 top-k 後要求模型只根據取得段落回答並列出文件名稱及來源 URL。
3. 讓學生試問 `問題集.csv`，比較 top-k = 1 與 3，以及純 LLM vs. RAG。
4. 測試超出知識庫的問題，要求回答「目前文件沒有足夠資訊」。
5. 進階課：請學生從附上的官方網址自行抓取原始 HTML，去除導覽列後重新建庫，觀察摘要知識庫與長文件知識庫的差異。

時效：2026 年最低工資資訊於 03 號檔案註明。法規可能修訂，未來年度不可直接沿用；法律問題應查閱當時有效規定。

授權注意：資料為為教學目的另行編寫的短摘要，引用官方來源網址。若進一步擷取、再散布官方全文或圖片，請查核原站權利聲明、政府資料開放授權及個別資料授權。教材不保證特定案件的法律適用結果。
